# if-ink OS

## Release

if-ink OS v0.1.1。[ダウンロードとインストール](https://yiifanrecyclable.github.io/if-ink-OS/)。

Obsidianテストプラグイン0.1.4は原名MDを收件フォルダー（既定PicoBox）へ直接保存し、最後の実際の書き込みで同名を置換します。第一段階は本文のみ、画像は説明に置換し、添付を読み取らず、清単や版本ディレクトリを作りません。書き込み後に本文を再読検証します。[検証手順](plugins/obsidian-pico/INSTALL.md)。実サービスとデスクトップ/Android/iPhone検証は未完了です。

設定の通常テキストとピンイン候補はロック後も保持します。アプリパスワードはロック時に消去して非表示にし、復帰後に再入力できます。設定の復元前にTFカードへ変更前の全状態を保存し、通常の書き込み失敗時には設定・読書記録・WiFi・クラウド設定を戻します。戻す処理も失敗した場合は `.Pico-restore.before` を保持します。「TFカードから復元」を再実行すると、先に旧状態を復元してから再試行します。復旧中はバックアップの上書き保存を禁止します。このファイルも平文の接続パスワードを含むため、復旧前に削除しないでください。突然の電源断・カード抜去からの完全自動復旧は実機検証待ちです。

各入力画面は画面下端に固定した共通キーボードを使用し、カーソル編集・英字大小切替・ASCII記号に対応します。TFカードの詞組辞書により2〜4文字の中国語全拼入力を追加できます。[入力と辞書](docs/TEXT_INPUT.md)。

MindReset Read Pico RDP-G01-W 向けの独立版です。Pico Reader **0.3.3-rc83**を基にし、Nutstore 同期、Markdown 文書、独自ホーム画面を追加しています。公開版は **if-ink OS v0.1.1**です。基本読書・クラウド取得・最新画面はユーザー確認済みです。[ダウンロードと手動インストール](https://yiifanrecyclable.github.io/if-ink-OS/)。

if.6はFatFsの既存ファイルへのrename拒否による「同期成功なのに文書がない」を修正しました。ログ・索引の置換をTFカードに合わせ、候補ログを復旧してから進め、保存先の長さとSHA256を確認します。ロールバックを成功扱いにせず、実機再検証が必要です。

if.5ではクラウド直下のMD/EPUB/TXTを一覧にし、手動ファイルとプラグインの文書を同じ経路で取得します。旧清単・版本目录は削除せず一覧から除外します。強い版本標記がない場合は本文を二回読みハッシュを検証します。if.4の読書修正を含み、実機のクラウド検証は未完了です。

if.4ではrc88のEPUBメタデータ・表紙のスタック削減と12 KiB主タスクスタックを採用し、HTMLスタイル解析の一時状態をPSRAMに移しました。小さい注画像は本文と同じページに流し、複数画像を縦に配置します。これはブロック混在で、文字行内の上付きではありません。表紙の押下移動を削除し、本を切り替えた後も本文の先読みを復旧します。IFのMarkdown・同期・画面を維持し、rc88全体への更新ではありません。EPUB再起動の実機再検証が必要です。

WiFi/ホットスポット転送に「上传文档」を追加しました。空でない`.md`のみ、1文書256 KiBまでを`markdown/`へ保存し、同名置換は確認します。日付・ピンを保持し、内容が変わった場合だけ進捗をリセットします。受信・検証失敗時は旧文書を保持します。画像は既存の互換グレースケールPNG添付が必要で、画像付きノートにはObプラグインを推奨します。

if.3はカード抜去後にページとフォントの旧ハンドルを閉じ、再挿入時に一度だけ再マウントします。成功後に現在の画面を更新し、失敗時に繰り返しません。USBストレージ使用中はカードを奪いません。書き込み・更新中はカードを保持してください。実機の抜き差し検証は未完了です。

ホームの「最近阅读」は、左の細い列に直近の図書の表紙・進捗バー・書名・読書進捗率、右の広い列に最近読んだ文書4件を表示します。タップで読み続けられます。同期履歴の欄は廃止し、4週間の読書ヒートマップは維持します。

設定画面上部は枠なしの「Pico Reader if Edition」「based on Pico Reader 0.3.3-rc83」に変更し、元の高さを保ちます。アバターと端末名の編集機能は廃止しました。

ホームは上から大きな日付と固定の格言、読書記録、下部ナビゲーションに隣接する最近の読書を表示します。バナーは日付・曜日・旧暦、ブランド名、大きな文字の3行です。ブランド名の左右に文字の高さ中央へ細い横線を置き、全体幅はセクション区切り線より少し狭くしています。文字は既定96px、スライダーで48–120pxを2px単位で調整でき、最大2行に折り返します。指を離すと実際の表示を更新して有効なサイズを保存し、2行を超える場合は以前のサイズを保持します。日付は1行に収まる最大サイズ、3行は同じ14pxの余白で上寄りに配置し、折り返し時は下にだけ2行目を追加します。長押しするとホームと同じサイズの実表示プレビューを開き、文字・専用TFフォント・サイズ・配置（左揃え・右揃え・中央・両端揃え）を変更できます。上の2行は中央揃え、格言も既定は中央です。両端揃えは各行の字間（英語は優先的に単語間）を広げ、1文字の場合は中央に表示します。文字やフォント変更後はプレビューに戻り、「完了」でホームに戻ります。文字・フォント・サイズ・配置は設定バックアップに含まれます。ヒートマップは角のある方形、今日の下線、月初を含む週の月名略称を表示します。各月1日のマス右上に小さな「1」を付け、薄い背景は黒字、中間灰色より濃い背景は白字にします。

下部ナビゲーションは文字なし・高さ80pxで、各項目が画面幅の4分の1を占める長方形です。選択中の領域全体を濃いグレー、アイコンを白で表示します。

WeRead、EPUB/TXT とファイル転送を継承します。ナビゲーションは文字なし、80 px、選択時は黒背景です。オンライン OTA は停止しています。

図書は装飾なしの3行3列の表紙表示に固定し、表紙の下に数値なしの読書進捗バー、次に書名を表示します。本棚スタイル設定は廃止しました。図書と文書には独立した管理・並べ替えボタンがあります。名前、読書進捗、追加日、最近の読書で並べ替え、共通の並べ替え画面を使います。お気に入り・スターの表示や絞り込みは廃止し、ピン留めを常に優先します。設定はバックアップに含まれます。図書と文書の長押し詳細は共通形式の浮動カードで表示し、図書のピン留めは設定バックアップに含まれ、文書のピン留めはTFカードの索引に保存します。管理画面のレイアウトを統一し、図書と文書を独立して検索できます。文書の一括操作は進捗クリアと削除で、文書のスターは廃止し、ピン留めは個別の長押し操作のみです。共有画像は削除しません。[操作説明](docs/CONTENT_LIBRARY.md)を参照してください。

画像識別子は `Read_Pico_IF`。原版からの初回移行には USB による完全インストールが必要です。以後の TF 更新ファイルは `Pico-IF-update.bin`、設定の更新画面で使用します。既存の上流 Web フラッシャーと `flash/` バイナリは IF の配布物ではありません。

Nutstoreの設定は端末で手入力します。TFカードからのJSON設定インポートはありません。設定バックアップには同期フォルダー、アカウント、アプリパスワードも含まれ、復元できます。バックアップは平文のWiFi・Nutstoreパスワードを含むため、安全に保管してください。Nutstore設定を含まない旧バックアップの復元では、現在のNutstore設定を維持します。

Markdown の「字体设置 → 标题与正文字号 · 效果预览」で、本文とH1/H2/H3のサイズを個別に設定し、使用中のフォントでプレビューできます。初期値は48/72/64/56px、H4〜H6は本文サイズの太字です。文書全体で共有し、本のサイズとは別に保存・バックアップされます。スライダーを離すと保存し、元の文字位置を基準に再ページ分割します。太字、斜体、`==ハイライト==`と組み合わせに対応し、ハイライトは薄い灰色背景の黒文字です。太字・斜体は同じフォントから合成し、追加フォントは不要です。コードとエスケープされた記号はそのまま表示します。

ESP-IDF v6.1 でビルドしてください。詳しい操作、制限、フォント配布は [English README](README.md)、[中国語 README](README.zh-CN.md)、[フォント](assets/fonts/README.md)を参照してください。原著作権と各コンポーネントのライセンスを維持します。

この版ではBluetoothページ送りと通信スタックを削除し、ファームウェアと実行時メモリを軽量化しています。

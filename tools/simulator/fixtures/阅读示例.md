# 给阅读留一点空间

每天打开一本书，读上几页。文字不会催促你，屏幕也不需要一直亮着。

这个项目希望把笔记变成可以安静阅读的文档。在电脑或手机上整理内容，发送以后，在 Pico 上选择下载，再离线阅读。

## 今天想读什么

- 一本读到一半的书
- 一篇值得慢慢看的文章
- 昨天写下的笔记

> 阅读不是为了赶上更多信息，而是为了更清楚地理解手边的内容。

## 清晰，比复杂更重要

标题帮助我们找到方向，段落给内容留出呼吸。列表、引用和图片，也应该在小屏幕上保持清楚。

下面是一段代码。代码里的标记会作为原文保留：

```text
reading = "每天读一点"
    [保持缩进]
```

## 把一页读完

你可以点击屏幕右半边翻到下一页，点击左半边返回。调整字号后，分页也会使用同一套字体度量重新计算。

图片读取还在开发中，第一版解析器显示替代文字：

![一张纸和一本书](assets/reading.png)

关闭网络以后，已经下载的文档仍应能够阅读。这是我们要做好的第一件事。

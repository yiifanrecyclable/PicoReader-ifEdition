在线安装

在线安装无需安装 Python 或刷机工具。请先备份重要数据；首次从原版迁移会重写分区表，原版内置存储数据不保证保留。

  1. 在电脑 Chrome 或 Edge 中打开本页。
  2. 唤醒 Pico，用可传数据的 USB-C 线连接电脑。退出 USB 读卡模式，关闭其他占用串口的工具。
  3. 点击下方连接按钮，选择 Pico 对应的串口。
  4. 按弹窗提示确认安装，保持连接，等待完成并重启。随后核对当前版本为 0.3.3-rc83-if.7。

手动安装（备用）

USB 完整安装

  1. 备份 TF 卡上的书籍、文档和设置，解压 USB 安装包。首次迁移会重写分区表，原版内置存储数据不保证保留；不要格式化 TF 卡或擦除整片 Flash。
  2. 电脑安装 Python 3 和 esptool，唤醒 Pico 后用 USB 数据线连接。退出 USB 读卡模式并关闭其他串口工具。
  3. 在解压后的包目录打开终端，将下面的 PORT 换成实际串口名。Mac 通常为 /dev/cu.usbmodem…，Windows 在设备管理器查看 COM…。

Mac 安装工具：python3 -m pip install esptool==5.4.0

Mac 写入：

python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args

Windows 使用同一命令，将 python3 换成 py。连接不稳定可将波特率改为 115200。保持包内目录结构，勿添加擦除命令；本机型没有 BOOT/RESET 物理按键。

等待四段写入与校验完成，重启后检查当前版本为 0.3.3-rc83-if.7，确认界面可响应。flash_args 来自同版构建：0x0 引导器、0x8000 分区表、0xd10000 OTA 初始数据、0x10000 应用，dio / 80m / 16MB。

后续 IF 更新：TF 卡

  1. 完整关机后取卡，用读卡器接电脑，解压 TF 更新包。
  2. 把 Pico-IF-update.bin 复制到 TF 卡根目录，替换旧同名文件，安全弹出后插回 Pico。
  3. 开机并保持足够电量或 USB 供电。进入设置 → 升级和恢复 → 系统升级，核对待安装版本，按提示安装并等待重启。

原版 Pico Reader 的 TF 升级不接受 IF 镜像，首次请使用上方在线安装或备用 USB 完整安装。

字体、词库与同步

首次解压资源包，将 TF卡资源 内的 fonts 和 system 文件夹合并到卡根目录。最终应有 fonts/PicoSans-Medium.ttf 和 system/ime/pinyin.ifdict，并保留随附许可文件。资源包只含固定授权标准字体和离线词库。

在文件页进入坚果云同步，填写自己的账号、应用密码及阅读目录，刷新后选择文档下载，再从内容页离线阅读。不要公开密码或含凭据的设置备份。下载包不含账号配置。

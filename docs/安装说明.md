# Pico Reader IF Edition 安装说明

版本：0.3.3-rc83-if.8。仅适用 Pico RDP-G01-W（ESP32-S3、16 MB Flash）。
基于 Pico Reader 0.3.3-rc83，选择性采用 rc88 阅读改进。if.8 新增 Markdown 表格显示，支持自动换行、续页表头与宽表展开。支持坚果云同步、Markdown 离线阅读，以及调整后的首页与操作界面。

## 首次安装：在线安装

在线安装无需安装 Python 或刷机工具。请先备份重要数据；首次迁移会重写分区表，原版内置存储数据不保证保留。原版 TF 升级不接受 IF 镜像。

1. 在电脑 Chrome 或 Edge 中打开安装页：https://yiifanrecyclable.github.io/if-ink-OS/
2. 唤醒 Pico，用可传数据的 USB-C 线连接电脑。退出 USB 读卡模式，关闭其他占用串口的工具。
3. 点击“连接 Pico，安装固件”，选择 Pico 对应的串口。
4. 按弹窗提示确认安装，保持连接，等待完成并重启。随后在“设置 → 升级和恢复 → 系统升级”核对当前版本为 `0.3.3-rc83-if.8`，确认界面可响应。

在线安装使用 [ESP Web Tools](https://esphome.github.io/esp-web-tools/)。找不到串口时，先检查数据线、设备是否唤醒及串口是否被其他工具占用，再重新连接。

## 手动安装（备用）

如果无法使用在线安装，可以下载 USB 完整安装包，按下面的备用方法安装。不要格式化 TF 卡，也不要擦除整片 Flash。

1. 下载 USB 安装包，解压。准备可传数据的 USB-C 线，把 Pico 唤醒后接到电脑。关闭串口监视器、其他刷机工具，并退出 USB 读卡模式。
2. 安装 Python 3。在 Mac 终端执行 `python3 -m pip install esptool==5.4.0`；Windows 命令提示符执行 `py -m pip install esptool==5.4.0`。如果 Python 提示环境受管理，可新建虚拟环境后安装；不要修改系统 Python 限制。
3. 在解压出的 USB 包目录打开终端。Windows 可在该文件夹地址栏输入 `cmd` 回车；Mac 在终端输入 `cd `（末尾留空格），拖入解压后的文件夹，再回车。
4. 查询串口：Mac 执行 `ls /dev/cu.*`，通常选择插上设备后新增的 `/dev/cu.usbmodem…`；Windows 在设备管理器“端口 (COM 和 LPT)”查看 `COM…`。下方 PORT 必须换成实际串口名，不要照抄。
5. Mac 执行：

```sh
python3 -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args
```

Windows 执行：

```bat
py -m esptool --chip esp32s3 --port PORT --baud 460800 --before default-reset --after hard-reset write-flash @flash_args
```

若出现串口权限/占用/连接失败，先关闭占用程序、换数据线或 USB 端口，再试；若高速传输不稳定，把 `460800` 改为 `115200`。设备没有 BOOT/RESET 物理按键，通常由工具自动进入下载模式。现有固件若提供“进入 BOOT 模式”菜单，也可使用该菜单后重试。不要添加 `erase-flash`。

6. 等待全部写入与校验完成，设备重启。核对“设置 → 升级和恢复 → 系统升级”中的当前版本为 `0.3.3-rc83-if.8`，确认触摸及书架可响应。

包内 `flash_args` 直接来自该版本构建：dio / 80m / 16MB；0x0 bootloader/bootloader.bin、0x8000 partition_table/partition-table.bin、0xd10000 ota_data_initial.bin、0x10000 Read_Pico_IF.bin。保持四段文件原目录和名称，不使用原作者 flash/ 文件替换。写入校验成功仍须确认设备已正常启动。

## 后续已经安装 IF：TF 更新

1. 设备完整关机后取出 TF 卡，用读卡器接电脑，解压 TF 更新包。
2. 只把 `Pico-IF-update.bin` 放到 TF 卡根目录（打开 TF 卡后直接可见），替换旧同名文件，不放入 books 或 markdown。
3. 安全弹出，插回 Pico 并开机。保持足够电量或 USB 供电。
4. 打开“设置 → 升级和恢复 → 系统升级”，确认待安装版本为 `0.3.3-rc83-if.8` 后安装，按提示确认并等待重启；完成前不要拔卡或断电。
5. 核对当前版本，然后确认本地文档能打开。升级不要求更换 Obsidian 插件或重新填写已有账号。

## 首次准备 TF 字体和词库

解压“TF 资源包”，将 `TF卡资源` 内的 `fonts` 和 `system` 文件夹合并到 TF 卡根目录，保留其他文件。不要把外层“TF卡资源”文件夹一起放到卡上。

最终路径：`fonts/PicoSans-Medium.ttf`、`fonts/PicoSans-OFL.txt`、`system/ime/pinyin.ifdict`、`system/ime/pinyin.LICENSE.txt`、`system/ime/pinyin.README.txt`。已有同名不同来源资源时先备份。标准字体用于完整中文标题、正文和候选字；词库提供离线拼音词组。缺少它们时基础菜单仍可显示，但字形及输入候选会受限。后续 IF 更新已有这些文件无需重装。

## 坚果云使用

在设备文件页进入坚果云同步，填写自己的账号、应用密码和阅读目录，刷新目录后选择需要的文档下载。下载完成后在内容页打开，断网也可阅读。使用坚果云应用密码，勿填写主登录密码；不要公开账号、密码或含凭据的设置备份。公开下载包不含任何账号配置。
